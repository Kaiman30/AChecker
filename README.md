# SS Checker

Автоматическая проверка ПК на читы для Minecraft по базе знаний из папки `SS/`.
Программа проходит по методикам базы (артефакты, реестр, журналы, службы, память процессов, моды, обходы)
и сохраняет понятный лог и отчёт с доказательствами: пути, время, источник, ссылки на скачивание,
ссылки на статьи базы и инструменты для ручной перепроверки.

Только стандартная библиотека Python, ничего не устанавливает на проверяемый ПК и ничего не отправляет в сеть.

## Сборка и запуск

```bat
build.bat                 :: собирает dist\SS_Checker.exe (нужен Python 3.8+ на ПК сборки)
SS_Checker.exe            :: на ПК подозреваемого, от администратора (UAC запросится сам)
```

Без сборки: `python ss_checker.py` (Python 3.8+ на Windows).

Результат появляется рядом с программой в папке `SS_Report_<ПК>_<дата>`:

| Файл | Что внутри |
|---|---|
| `report.html` | Отчёт для модератора: вердикт, находки по критичности, доказательства, таблицы собранных данных, хронология |
| `report.json` | То же для машинной обработки |
| `scan.log` | Полный лог проверки |

### Параметры

| Параметр | Назначение |
|---|---|
| `--since "2026-10-10 14:05"` | Время вызова на проверку. Всё, что изменено после него, помечается «незадолго до проверки» |
| `--hours 3` | То же окно в часах от момента запуска (по умолчанию 3) |
| `--quick` | Искать файлы только в профиле пользователя, а не на всех дисках |
| `--path D:\Games\MC` | Дополнительная папка (нестандартный лаунчер/папка игры), можно несколько раз |
| `--no-memory`, `--no-usn` | Пропустить память процессов / USN-журнал |
| `--memory-limit 768` | Сколько МБ памяти читать из одного процесса |
| `--out D:\reports`, `--no-open`, `--no-pause`, `-v` | Куда сохранять, не открывать отчёт, не ждать Enter, подробный лог |

Запускайте, пока Minecraft открыт: тогда проверяются память игры, загруженные DLL и «выгруженные» моды.

## Что проверяется (соответствие базе)

| Раздел базы | Проверка |
|---|---|
| Артефакты: BAM, UserAssist, ShimCache, PCA, Prefetch, Recent, JumpLists, корзина, планировщик, ActivitiesCache, USN | Разбор всех источников следов запуска → сводная хронология; файлы с названиями читов, удалённые после запуска, запуск с изменённым расширением, с флешки; очистка Prefetch/корзины/USN |
| Программы → System Informer | Чтение памяти DPS, PcaSvc, Explorer, DiagTrack, DcomLaunch, SysMain, Dnscache, AppInfo, SearchIndexer, BFE, Scheduler, CDPUserSvc, csrss, MsMpEng, PowerShell, javaw по регуляркам из базы |
| Программы → Everything | Поиск по списку имён, точным размерам `Jar Sizes` / `Size by Weight`, vec.dll, сигнатура Doomsday |
| Win+R | JavaLauncher.log, JNativeHook и Rar$EX в %TEMP%, история PowerShell, UsageLogs, CrashDumps, Prefetch |
| Eventvwr | 1102/104 (очистка журналов), 3079 (удаление USN), смена времени, остановка служб (7036/7040), 7045, PowerShell 4104/400/600, 4688, BITS, PCA, Kernel-PnP, Defender, глубина журналов |
| Реестр | RunMRU, TypedPaths, WordWheelQuery, RecentDocs, OpenSavePidlMRU, MuiCache, Compatibility Store, автозагрузка, CMD AutoRun, DisallowRun/IFEO/запреты, EnablePrefetcher, WinRAR/7-Zip, OpenWithList, USBSTOR и setupapi.dev.log |
| Службы | Состояние и тип запуска, перезапуск после загрузки, приостановленные потоки |
| Сеть | Все параметры из раздела «Сеть» (Tcpip, Interfaces, AFD, QoS, SystemProfile, параметры сетевой карты) и `netsh int tcp show global` |
| Моды | Дата папки mods, разбор каждого .jar (обфускация a.class/IIII, DLL внутри, keywords.txt, строки KillAura/Reach, пакеты module/combat, методы из базы, метаданные), вес мода по таблице, логи игры, `-javaagent`, выгруженные моды |
| Обходы | Виртуальные машины, WinRM, переименованный Prefetch, атрибуты .pf, ADS, стеганография, файлы с поддельным расширением, Unicode-имена, URL-протоколы (Execute Web), hosts, «Опасные сайты», ShellBag Cleaner, USBOblivion, подмена дат и hex replace (по USN), поддельные подписи |

## Ограничения

- Отчёт не выносит решение сам. Каждая находка — повод перепроверить её указанным инструментом.
- Защищённые процессы (MsMpEng, обычно csrss) без драйвера ядра не читаются — смотрите их в System Informer.
- Amcache, SRUM, $MFT и ShellBags заблокированы системой или требуют сложного разбора — для них в отчёте
  есть ссылки на AmcacheParser, SRUMECmd, MFTECmd и ShellBagAnalyzer.
- Интерактивные приёмы (цвет текста в CMD, Legacy console, раздел «Использование данных») остаются ручными.
